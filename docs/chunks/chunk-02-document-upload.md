# Chunk 02: Document Upload

## Status

Planned.

## Goal

Allow users to upload PDF documents and extract text from them on the backend.

## What We Will Build

- PDF upload UI.
- Backend upload endpoint.
- File validation for PDF type and size.
- Local file storage for development.
- PDF text extraction service.
- Basic document metadata model.
- Upload success and error states in the UI.

## Concepts

- Multipart file uploads.
- Document parsing.
- Text extraction.
- Backend file handling.
- Input validation and safety checks.

## Expected Deliverable

A user can upload a PDF, and the backend extracts readable text from it.

## Next Goal

Chunk 03 will split extracted document text into chunks and generate embeddings.
