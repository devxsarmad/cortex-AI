# Chunk 04: Vector Database

## Status

Planned.

## Goal

Store embeddings in a vector database and retrieve the most relevant chunks for a query.

## What We Will Build

- Qdrant setup for local development.
- Collection creation and configuration.
- Vector upsert service.
- Similarity search service.
- Metadata filters for document-level retrieval.

## Concepts

- Vector databases.
- Collections.
- Indexing.
- Top-K search.
- Similarity scores.

## Expected Deliverable

Document chunks are stored in Qdrant and can be searched semantically.

## Next Goal

Chunk 05 will connect retrieval to the chat endpoint and generate answers from uploaded documents.
