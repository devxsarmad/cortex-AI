# Chunk 05: RAG

## Status

Planned.

## Goal

Answer user questions using retrieved content from uploaded PDFs.

## What We Will Build

- Query embedding flow.
- Retriever service.
- RAG prompt template.
- Context injection into the LLM request.
- Basic citation output from chunk metadata.
- Guardrails for document-grounded answers.

## Concepts

- Retrieval-Augmented Generation.
- Context construction.
- Prompt injection prevention.
- Source-grounded answering.
- Citations.

## Expected Deliverable

The assistant answers questions using uploaded PDF content and includes source references.

## Next Goal

Chunk 06 will expand retrieval across multiple documents with better metadata and citations.
